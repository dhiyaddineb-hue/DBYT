# 🎙️ DBYT — دوبلاج فيديو احترافي (Professional Video Dubbing)

حوّل أي فيديو (يوتيوب أو ملف محلي) إلى **دوبلاج احترافي** بصوت بشري طبيعي يحمل
**نفس مشاعر المتحدث**، بعدة لغات، وبدقة توقيت عالية.

> **⚠️ ملاحظة:** هذا المستودع **خاص (Private)** — لا يمكن الوصول إليه إلا برابط
> الدعوة الذي يملكه المالك فقط.

> **🗄️ المستودع = الـ Workspace:** كل ملف يُنتَج (النماذج، الملفات المرفوعة،
> المهام، النواتج) يُخزَّن داخل مجلد واحد `workspace/` ويُرفَع إلى المستودع
> عبر **Git LFS** — لأن مساحة بيئة التشغيل المحلية محدودة بينما GitHub أوسع.
> راجع [`workspace/README.md`](workspace/README.md).

## ✨ المزايا

| الميزة | الوصف |
|---|---|
| ✅ **تعبئة اسم المشروع تلقائياً** | يُعبأ اسم المشروع من عنوان فيديو يوتيوب فور لصق الرابط |
| 🟢 **مؤشر أخضر لصحة الرابط** | يظهر مؤشر أخضر بجانب حقل الرابط عندما يكون الرابط صحيحاً |
| ⬆ **رفع فيديو محلي** | ادبلج أي ملف فيديو/صوت من جهازك (سحب وإفلات) |
| 🎭 **مشاعر المتحدث** | يكتشف الانفعال (فرح/حزن/غضب/مفاجأة) ويطبّقه على الصوت الجديد |
| 🌍 **لغات متعددة** | 13+ لغة هدف: عربي، فرنسي، إنجليزي، إسباني... |
| ⏱️ **توقيت دقيق** | محاذاة كل جملة مع حركة شفاه المتحدث عبر Whisper (word timestamps) |
| 🎯 **دقة على مستوى الكلمة** | كل كلمة تُولَّد وتُمدَّد وتوضع في لحظتها الزمنية الدقيقة في الفيديو |
| 👄 **مزامنة شفاه (Wav2Lip)** | إعادة تحريك الفم ليطابق الصوت الجديد — يبدو الفيديو **أصلياً لا دوبلاج** |
| 🎵 **خلفية موسيقية** | إبقاء الموسيقى والأصوات الخلفية تحت الصوت الجديد |
| 🧩 **محركات صوت متعددة** | Edge-TTS (مجاني) / ElevenLabs (مشاعر حقيقية) / Bark / XTTS |
| ☁️ **GitHub Actions** | شغّل خط أنابيب الدوبلاج على خوادم GitHub دون جهاز قوي |

```

│   ├── app/
│   │   ├── main.py              # تطبيق FastAPI (الواجهة الخلفية + تقديم الواجهة)
│   │   ├── config.py            # الإعدادات (من متغيرات البيئة)
│   │   ├── schemas.py           # نماذج الطلب/الاستجابة
│   │   ├── routes/              # مسارات API
│   │   │   ├── youtube.py       #   /api/youtube/info (تحقق + تعبئة الاسم)
│   │   │   ├── upload.py        #   /api/upload (رفع ملف)
│   │   │   └── dub.py           #   /api/dub, /status, /results
│   │   └── services/            # خط أنابيب الدوبلاج
│   │       ├── youtube.py       #   yt-dlp: تحميل + بيانات وصفية
│   │       ├── transcribe.py    #   faster-whisper: نسخ الكلام بتوقيت الكلمات
│   │       ├── translate.py     #   ترجمة (Google/OpenAI)
│   │       ├── emotion.py       #   اكتشاف الانفعال -> معاملات النبرة
│   │       ├── tts.py           #   محركات الصوت (Edge/ElevenLabs/Bark/XTTS)
│   │       ├── audio.py         #   تمديد الزمن + دمج (ffmpeg)
│   │       ├── pipeline.py      #   منسق الخطوات
│   │       └── jobs.py          #   إدارة المهام (خلفية + متابعة الحالة)
│   └── cli.py                   # واجهة سطر أوامر (تُستخدم في Actions والإنتاج)
├── frontend/                    # واجهة الويب (RTL عربية، بدون خطوة بناء)
├── deploy/                      # Compose الإنتاج، Caddy، systemd، ونشر SSH
├── .github/workflows/main.yml   # تشغيل مؤقت للدوبلاج على GitHub Actions
├── .github/workflows/deploy.yml # نشر تلقائي إلى الخادم الإنتاجي
├── Dockerfile / docker-compose.yml
└── requirements.txt
```

### كيف يعمل الدوبلاج (خطوة بخطوة)

1. **التحميل** — يستخدم DBYT مسارًا مصرحًا به مثل `yt-dlp` مع Proxy أو Cobalt API؛ browser downloader العام اختياري وليس مسارًا مضمونًا.
2. **النسخ** — `faster-whisper` يستخرج الكلام مع **توقيت كل كلمة**.
3. **الترجمة** — `deep-translator` (أو OpenAI) يترجم كل جملة للغة الهدف.
4. **الانفعال** — `emotion.py` يكتشف شعور كل جملة ويحوّله لمعاملات نبرة
   (سرعة/نغمة/علوّ) تُنقل لمحرك الصوت.
5. **التوليد** — محرك TTS يركّب الصوت باللغة الهدف مع النبرة المناسبة.
6. **المحاذاة على مستوى الكلمة** — كل كلمة تُمدَّد/تُضغَط (`ffmpeg atempo`)
   لتُطابق مدة الكلمة الأصلية ثم تُوضَع في لحظتها الزمنية الدقيقة
   (`place_clips_at_times`) — "كل كلمة في مكانها".
7. **الدمج** — يمزج الصوت الجديد فوق الخلفية الأصلية ثم يُركّب في الفيديو.
8. **مزامنة الشفاه (اختياري)** — `Wav2Lip` يعيد تحريك فم المتحدث ليطابق الصوت
   الجديد، فيبدو الفيديو وكأنه صُوِّر باللغة الهدف أصلاً.

## 🚀 التشغيل

### المتطلبات
- Python 3.10+ ، و **ffmpeg** (نظامي): `sudo apt install ffmpeg`

### 1) التشغيل محلياً

```bash
git clone <رابط-المستودع-الخاص> && cd DBYT

python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
sudo apt install ffmpeg        # إن لم يكن مثبتاً

# تشغيل الواجهة (الواجهة الخلفية + الأمامية معاً)
cd backend && uvicorn app.main:app --host 0.0.0.0 --port 8000
```

افتح http://localhost:8000

### 2) التشغيل عبر Docker

```bash
docker compose up --build
```

### 3) التشغيل عبر GitHub Actions (مؤقت)

1. اذهب إلى تبويب **Actions** في المستودع.
2. اختر **Dubbing Pipeline** ثم **Run workflow**.
3. أدخل رابط يوتيوب واللغة الهدف، ثم شغّل.
4. حمّل النتيجة من **Artifacts** (`dubbed-video`).

هذا المسار يعمل على runner مؤقت، وقد يحجب YouTube عنوان IP الخاص به. للتشغيل المستمر استخدم ملفات [`deploy/README.md`](deploy/README.md) و`deploy/docker-compose.prod.yml`.

### 4) الاستضافة الإنتاجية

يحتوي المستودع الآن على حزمة نشر كاملة: حاوية DBYT غير root، Caddy لـ reverse proxy وHTTPS، volumes دائمة، healthchecks، systemd، وWorkflow نشر عبر SSH. شغّلها من [`deploy/README.md`](deploy/README.md). يجب تعريف `DBYT_API_KEY` على الخادم قبل فتح الخدمة للعامة، وعدم وضع cookies أو مفاتيح API داخل المستودع.

## 🎛️ إعدادات الصوت والمشاعر

| المحرك | الجودة | المشاعر | التكلفة | ملاحظات |
|---|---|---|---|---|
| **Edge-TTS** | جيدة جداً | عبر تعديل النبرة | مجاني | الافتراضي، سريع على CPU |
| **ElevenLabs** | ممتازة (بشرية) | حقيقية (أصلية) | مدفوع | ضع `DBYT_ELEVENLABS_API_KEY` |
| **Bark** (Suno) | جيدة | أصيلة (رموز انفعال) | مجاني | ثقيل، يفضّل GPU |
| **XTTS-v2** (Coqui) | ممتازة | استنساخ صوت المتحدث | مجاني | يفضّل GPU |

**لأعلى جودة مشاعر**، فعّل ElevenLabs:
```bash
DBYT_ELEVENLABS_API_KEY=your-key
```
ومحرك الصوت `elevenlabs` من الواجهة أو عبر `--engine elevenlabs`.

## 👄 مزامنة الشفاه (لتبدو أصلية لا دوبلاج)

لجعل الفيديو يبدو أنه **صُوِّر باللغة الهدف أصلاً**، فعّل خيار "مزامنة الشفاه"
(أو `--lip-sync true` / `DBYT_LIP_SYNC=true`). يستخدم المشروع **Wav2Lip**
([github.com/Rudrabha/Wav2Lip](https://github.com/Rudrabha/Wav2Lip)) — النموذج
المفتوح المصدر القياسي لإعادة تحريك الفم ليطابق الصوت.

- **المتطلبات:** GPU موصى بها بشدة + أوزان النموذج (~450 م.ب) تُنزَّل تلقائياً
  إلى `workspace/models/` (تُحفظ في المستودع عبر Git LFS).
- عند التعذّر (لا GPU / لا أوزان) يتخطّى الخط الأنابيب هذه المرحلة بأمان ويُسلّم
  الفيديو المدبلج صوتياً فقط.

> للدقة القصوى مستقبلاً: يمكن استبدال Wav2Lip بـ **WhisperX** (محاذاة كلمات
> أدق) أو **Video-Retalking** / **EchoMimic** (جودة أعلى). راجع قسم Roadmap.

## 📡 واجهة API

| الطريقة | المسار | الوصف |
|---|---|---|
| `POST` | `/api/youtube/info` | التحقق من الرابط وجلب العنوان (للمؤشر الأخضر + تعبئة الاسم) |
| `POST` | `/api/upload` | رفع ملف فيديو/صوت محلي |
| `POST` | `/api/dub` | بدء مهمة دوبلاج |
| `GET` | `/api/status/{job_id}` | متابعة حالة المهمة والتقدم |
| `GET` | `/api/results/{job_id}/download` | تحميل الفيديو المدبلج |
| `GET` | `/api/health` | فحص الصحة |
