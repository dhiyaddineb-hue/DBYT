# 📁 workspace/ — المجلد الوحيد لكل ما يُنتَج

هذا هو **الـ Workspace** الكامل للتطبيق. كل ملف يُنتجه DBYT يُخزَّن هنا
(وليس في أي مكان آخر)، ويُرفَع إلى مستودع GitHub عبر **Git LFS**.

```
workspace/
├── models/     # أوزان النماذج (Whisper, Wav2Lip, ...) — تبقى محفوظة في المستودع
├── jobs/       # ملفات كل مهمة دبلجة (المصدر + المراحل + النتيجة)
├── uploads/    # الملفات التي يرفعها المستخدم
├── output/     # الفيديوهات المدبلجة النهائية
├── data/       # بيانات مساعدة
└── logs/       # سجلات التشغيل
```

## حفظ النتائج في المستودع (GitHub = مساحتك)

عندما تنتهي مهمة دبلجة، احفظ الناتج في المستودع:

```bash
# مرة واحدة فقط على جهازك:
git lfs install

# بعد أي دبلجة:
./scripts/sync_workspace.sh "دبلجة فيديو X"
```

أو يدوياً:
```bash
git add workspace && git commit -m "store dubbing output" && git push
```
